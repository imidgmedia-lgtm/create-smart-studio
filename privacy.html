Privacy Policy

Project: Create Smart Studio

Last updated: October 24, 2026

1. About This Project

Create Smart Studio is a personal desktop software project currently under development. Its first module, Pinterest Niche Scout, is intended for Pinterest-related research and content planning.

2. Information Accessed

Subject to authorization and available API permissions, the application may access Pinterest keyword and trend information, as well as information and analytics from the Pinterest account authorized by its user.

3. How Information Is Used

Information is intended to be used for personal research, comparing content topics, preparing reports, and reviewing the performance of the authorized account.

4. Data Storage

The application is designed to store research settings and generated reports locally on the user's computer. Storage practices may be updated as development continues.

5. Data Sharing

The project does not currently operate a service that sells Pinterest account data or distributes it to third-party customers. API requests, if enabled, are made to Pinterest's official services.

6. Account Authorization

Access to account-specific information will require appropriate authorization. Users may revoke application access through applicable Pinterest account settings.

7. Security

Access credentials are intended to be stored locally and excluded from publicly published source files. No method of electronic storage is completely secure.

8. Changes

This policy may be revised as application features and data practices evolve. Updates will be published on this page.

9. Contact

For project information, visit the Create Smart Studio homepage.
